# Parliamo · learn-italian-dialogs

Україномовний сайт для практики італійських діалогів голосом.

## Запуск

Потрібен Node.js 20 або новіший. Сторонніх залежностей немає.

```sh
npm start
```

Сервер використовує порт 3000 (або змінну `PORT`). Для мікрофона відкривайте сайт через HTTPS або localhost. Найкраще почати з актуального Chrome: підтримка SpeechRecognition залежить від браузера та пристрою.

## Як тренуватися

1. Вставте діалог: кожна репліка з нового рядка, наприклад `Anna: Ciao!` та `Marco: Ciao Anna!`.
2. Натисніть «Налаштувати ролі», виберіть свою роль.
3. Перевірте голоси й натисніть «Послухати». Для невідомих імен виберіть тип голосу вручну. Без імен ролі чергуються між двома персонажами.
4. Почніть розмову та дозвольте використання мікрофона. Комп'ютер читає свої репліки й слухає ваші.
5. Ваша репліка одразу видима на картці. Кнопка «Приховати текст» приховує її, «Показати текст» повертає.
6. Якщо відповідь збігається з текстом, діалог продовжується автоматично. Якщо відрізняється, можна повторити, показати текст або продовжити.

## Межі першої версії

- Визначення типу голосу за іменем використовує невеликий словник італійських імен. Його можна виправити вручну.
- Web Speech API не повідомляє стать голосу. Вибір використовує відомі назви голосів, але точний голос потрібно перевірити на своєму пристрої. За відсутності потрібного голосу його треба додати в системних налаштуваннях.
- Порівнюється розпізнаний текст, а не якість вимови чи граматика. Інші правильні формулювання можуть не збігтися зі зразком.
- Розпізнавання може потребувати інтернету та передавати аудіо провайдеру браузера. Застосунок не записує й не зберігає аудіо. Якщо мікрофон недоступний, можна вводити відповідь текстом.
- Для справжньої оцінки вимови потрібна окрема інтеграція з мовним сервісом.

## Перевірки

```sh
npm test
node --check app.js
```

Автотести перевіряють розбір реплік, визначення імен і порівняння відповідей. Озвучення, дозвіл мікрофона та якість розпізнавання потрібно перевіряти вручну в браузері на реальному пристрої.

Жіночий голос за замовчуванням: Google italiano, якщо доступний. Чоловічі голоси: перевага Diego Natural/Online, Cosimo, Diego, Luca та Paolo серед італійських голосів пристрою. Якість і доступність потрібно перевіряти прослуховуванням; застосунок не завантажує додаткові голоси.
